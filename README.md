# Lorena Macedo — Landing page

Site estático em português, com HTML, CSS e JavaScript, sem dependências de build.

## Visualizar

Sirva a pasta `dist` com qualquer servidor HTTP estático. Exemplo: `python -m http.server 8765 --directory dist`. Abra `http://localhost:8765`.

## Editar

- `dist/index.html`: textos, seções, links e campos.
- `dist/styles.css`: identidade, composição e regras responsivas.
- `dist/app.js`: menu, seleção de interesse, validação e mensagem para WhatsApp.
- `dist/assets`: logos, retratos e projetos extraídos dos materiais originais. Montserrat distribuída sob SIL Open Font License; licença na pasta de assets.

Os CTAs usam o número confirmado +55 63 99939-6569. O formulário não grava nem envia dados a um servidor: prepara uma mensagem e abre o WhatsApp; o visitante precisa concluir o envio. O link alternativo permanece disponível caso a janela seja bloqueada. Não há rastreadores ou armazenamento local.

As fotografias vêm do PDF de apresentação, com resolução limitada à disponível nesse material. Trocar por originais de maior resolução pode melhorar a nitidez em telas de alta densidade.

A configuração `.openai/hosting.json` identifica o Sites privado destinado à revisão. Não alterar o ID ao atualizar o mesmo site.

A fonte principal dos títulos é Athena Light, com a variante Light Italic para destaques, fornecida pelo usuário. Montserrat permanece nos textos e controles.
